## 🤖 ERP Agent

### AI-Powered Conversational ERP Assistant

An AI-powered ERP assistant that allows users to interact with business data using natural language.

Instead of navigating multiple ERP reports and filters, users can ask questions such as:

```text
"Which branch sold the most Bhakarwadi this month?"

"Which products are low in stock?"

"Show pending purchase orders."

"Which salesperson generated the highest revenue?"
```
